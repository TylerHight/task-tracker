# Task Tracker

## Purpose

Task Tracker is a personal focus and habit tracker. It should make it quick to
start a named activity, complete a flexible focus session, and build a useful
record of how time is spent.

## Intended MVP

- Start a new activity with only its name.
- Start a recently used activity in a few seconds.
- Pause, resume, cancel, or complete a flexible focus timer.
- Record optional activity-specific details when useful.
- Review activity history and simple trends.
- Keep records exportable and usable in a spreadsheet or by AI.

## Later capabilities

- Import and synchronize an existing Google Sheet.
- Publish completed sessions to a selected Google Calendar.
- Handle offline capture and reliable, duplicate-safe synchronization.

## Non-goals for the first version

- Social features, team time tracking, billing, or passive surveillance.
- AI coaching or two-way Google Calendar synchronization.
